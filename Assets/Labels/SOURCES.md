# Original bottle labels

These SVG layouts, borders, medallions, and ornaments are original Bartender Specialogist artwork by Navin Ratnayake, licensed under the repository's MIT License. Real-world brand names are plain-text references; these are not official labels or logos.

`scripts/generate_labels.py` produces the artwork with outlined Crimson Text lettering. The font is a development input from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/crimsontext), copyright 2010 The Crimson Text Project Authors, under the [SIL Open Font License 1.1](FONT-LICENSE.txt). The font binary is not distributed. The OFL does not require artwork created using the font to carry the font license.

The game loads the bundled SVGs directly; Python, FontTools, and the font are not runtime dependencies.
